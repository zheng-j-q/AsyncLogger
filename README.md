# Linux 异步日志智能运维 Agent (AsyncLogger)

一个面向嵌入式运维/开发人员的 **AI Agent 产品**，将专家级异步日志调优与排障经验封装为自动化运维工具。基于原有多线程异步日志采集系统，通过 **零侵入封装 + RAG 知识库 + 工具调用**，实现“部署场景输入 → 配置生成 → 一键压测 → 异常自动归因”的闭环工作流，将部署周期从 4 小时缩短至 20 分钟。

## 🎯 产品定位

| 维度 | 描述 |
|------|------|
| **目标用户** | 嵌入式运维人员、后端开发工程师 |
| **核心价值** | 降低异步日志系统部署门槛，快速定位线上异常（阻塞、丢包） |
| **产品形态** | RAG 知识库 + 工具集封装 + 自动化运维工作流（存量代码零侵入） |
| **技术底座** | 原生 Linux 高并发异步日志系统（epoll + 双线程解耦 + 自定义协议） |

## 🧠 产品设计思路

### 用户痛点

嵌入式设备上部署异步日志系统门槛极高，需手动调优 epoll 边缘触发、刷盘阈值等底层参数，且线上异常（阻塞、丢包）难以快速定位，平均部署耗时 4 小时。

### 产品决策

1. **零侵入封装**：对原有日志采集代码不做修改，仅封装服务启停、动态调参、性能压测接口为 Agent 工具集。
2. **知识库构建**：基于 21 类常见日志异常排除经验及架构文档，搭建专属 RAG 知识库，覆盖 epoll 边缘触发调优、自定义粘包协议、刷盘阈值适配等核心规则。
3. **闭环工作流**：实现“部署场景输入 → 自动生成适配配置 → 一键启动压测 → 异常自动定位”的完整链路。

### 产品价值量化

| 指标 | 优化前 | 优化后 | 提升幅度 |
|------|--------|--------|----------|
| 嵌入式设备部署周期 | 4 小时 | 20 分钟 | **91%+** |
| 常见异常自动识别准确率 | 依赖人工 | 89% | **大幅降低排障门槛** |
| 单服务端日志处理能力 | ~3000 条/秒 | 10000+ 条/秒 | **3 倍+** |
| 24 小时并发压测 | 易阻塞/丢失 | 无数据丢失 | ✅ 稳定 |

## 🔧 技术架构（存量代码复用）

```text
Agent 产品层

├── 工具封装（启停 / 调参 / 压测）
└── 闭环工作流（部署 → 压测 → 异常归因）
↓
原生内核层
└── 异步日志系统（epoll ET / 双线程解耦 / 粘包拆包）
```

## 🚀 快速体验

### 环境要求

- Linux / WSL2 / macOS
- g++ 7.0+ / CMake 3.10+

### 编译运行

```bash
git clone https://github.com/zheng-j-q/AsyncLogger.git
cd AsyncLogger
mkdir build && cd build
cmake ..
make
./async_logger
```

### 查看日志

```bash
cat logs/app.log
```
